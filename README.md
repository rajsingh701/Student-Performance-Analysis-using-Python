# 🎓 Student Performance Analysis using Python

## 📌 Project Overview

Education plays a crucial role in shaping future outcomes, and understanding the factors affecting student performance can help educators make informed decisions. This project analyzes student performance data using **Python** to identify the key factors influencing academic success.

Using **data cleaning**, **exploratory data analysis (EDA)**, **correlation analysis**, and **visualization techniques**, the project uncovers meaningful insights into how study habits, attendance, sleep duration, parental education, and other factors impact students' overall scores.

---

## 🎯 Objectives

- Analyze student academic performance.
- Identify factors affecting overall scores.
- Discover relationships between study habits and grades.
- Evaluate the impact of attendance and participation.
- Generate actionable insights for educators and institutions.

---

The dataset includes information such as:

- Sleep Duration
